# Thumbnail Cleaner for Linux Mint & Ubuntu

**A simple script to automatically clean up old thumbnail caches on Linux Mint & Ubuntu!**  
Frees up disk space by deleting outdated thumbnails.

## Features
- Automatically deletes all thumbnails older than 30 days
- Runs once per week using a systemd timer
- Easy installation & removal

## 🛠 Installation
```bash
git clone https://github.com/Wholffe/thumbnail-cleaner.git
cd thumbnail-cleaner
chmod +x setup-thumbnail-cleaner.sh
./setup-thumbnail-cleaner.sh
```
